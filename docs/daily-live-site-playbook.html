কীভাবে ব্যবহার করবেন দুই রকম কাজ ২ সপ্তাহের প্ল্যান শিখুন — ধাপ ১–১১ রোজকার চেকলিস্ট নিজেকে টেস্ট চার্ট যা স্কিপ করবেন
প্রতিদিন ২টা ভিডিও যথেষ্ট। প্রোগ্রেস এই ব্রাউজারে সেভ থাকে।

সাইট কীভাবে লাইভ হয়, আর প্রতিদিন কী আপডেট করবেন

আগে ওয়েব/ডোমেইন/হোস্টিং বুঝুন। তারপর CMS vs code আলাদা করুন। শেষে GitHub → hosting deploy। এই ফাইলটা প্রতিদিন খুলুন, টিক দিন, আগামীকাল যেখানে ছিলেন সেখান থেকে শুরু করুন।

Next.js + Prisma + PostgreSQL develop → main CMS = database, GitHub = code

কীভাবে এই ডক ব্যবহার করবেন

ইউটিউবে সার্চ টাইটেল হুবহু বসান। ১০–২০ মিনিট beginner ভিডিও নিন। দেখার পর নিচের বক্সে টিক দিন।

  1. প্রতি ভিডিওর পর জিজ্ঞেস করুন: এটা চার্টের কোন বাক্স — domain, hosting, নাকি database?
  2. বাংলা চ্যানেল intro-এর জন্য চলবে; DNS, Vercel, Postgres ইংরেজি ভিডিওতে পরিষ্কার।
  3. ভালো চ্যানেল: Fireship, NetworkChuck, freeCodeCamp, ByteByteGo, Hussein Nasser, Traversy Media, Cloudflare, Vercel।
  4. ধাপ ১–৩ শেষ না করে Vercel tutorial-এ যাবেন না।

সবসময় মনে রাখুন: দুই রকম কাজ

ইকমার্সে প্রতিদিনের কাজ আর কোড ডিপ্লয় এক জিনিস নয়। এই দুই কার্ডই পুরো বিজনেস।

পথ A — CMS / database

নতুন PDP, দাম, স্টক, warranty, ছবি

স্টাফ /admin-এ সেভ করে → API → PostgreSQL → কাস্টমার পেজ। GitHub লাগে না। merge to main-ও লাগে না।

পথ B — Code / hosting

নতুন ডিজাইন, ফিল্টার, ক্যাটাগরি পেজ, ফিচার

Cursor-এ কোড → develop → push → main → hosting build। এটাই deploy। প্রোডাক্ট লিস্ট একা আসে না।

২ সপ্তাহের প্ল্যান — ব্যস্ত মালিকের জন্য

প্রতিদিন দুটো ভিডিও। টিক দিলে প্রোগ্রেস সেভ হবে।

শিখুন — ধাপ ১ থেকে ১১

১–৭ ভিত্তি। ৮–১১ আপনার আসল লক্ষ্য: live site + everyday maintenance।

রোজকার চেকলিস্ট

এখন সাইট local। Live হলে নিচের দ্বিতীয় ব্লক ব্যবহার করবেন। দুই PC হলে প্রথম ব্লক আজকের নিয়ম।

এখন — বাসা / অফিস, live-এর আগে

প্রোডাক্ট দুই PC-তে আনতে GitHub backups লাগে

git pull শুধু কোড আনে। প্রোডাক্ট আসে sync:push → GitHub backups/ → অন্য PC-তে sync:pull। Cursor অ্যাকাউন্ট database কপি করে না। .env কখনো GitHub-এ যাবে না।

পরে — domain কেনা, সাইট লাইভ

তখন একটা production database; CMS সরাসরি সেখানে লেখে

Ready কিনা — ৫টা প্রশ্ন

উত্তর নিজে বলুন, তারপর বাক্সে টিক দিন। টিক দিলে নমুনা উত্তর খুলবে। এগুলো পারলে ধাপ ১–৭ ঠিকমতো বসেছে।

পাশে রাখুন — আপনার চার্ট

ভিডিও দেখার সময় বাক্সের সাথে মিলিয়ে নিন। ফাইলগুলো এই docs/ ফোল্ডারেই আছে।

Site architecture Domain → Cloudflare → Hosting → Next.js → Prisma → PostgreSQL, plus GitHub deploy. Owner workflow কী কিনতে হয়, কাস্টমার vs স্টাফ, কখন CMS আর কখন developer deploy।
